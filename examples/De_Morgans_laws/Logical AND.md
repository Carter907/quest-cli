## What is Logical AND?

In propositional logic, **Logical AND** (also called **conjunction**) is an operation that connects two propositions. 

The conjunction of two propositions $P$ and $Q$ is denoted as:

$$ P \land Q $$

(Read as *"P and Q"*).

### Truth Value Rule

A conjunction $P \land Q$ is **true** if and only if **both** $P$ and $Q$ are true. If either proposition (or both) is false, the entire statement is false.

### Examples

- **Natural Language:**
  - Let $P$ = "It is sunny."
  - Let $Q$ = "It is warm."
  - $P \land Q$ = "It is sunny and it is warm." *(True only when both weather conditions are true simultaneously).*

- **Mathematical:**
  - $(3 < 5) \land (2 + 2 = 4)$ is **True** because both components are true.
  - $(3 < 5) \land (2 + 2 = 5)$ is **False** because the second component is false.
