## Compound Logical Statements

In logic, you have various kinds of operators that you can use in order to relate truth values together to form a new condition.

For instance, if you wanted to check if two things are true at the same time, you would use a logical operation called a "logical and".

There are many other compound logical operators, but let's first look at truth tables and how those are related.

## Logical Equivalence

Two statements are logically equivalence if they always produce the same truth values for every combination of statements.

## Truth Tables

Truth tables can be used to see all possible combinations of truth values within a logical expression. You can use truth tables to prove that two statements are logically equivalent. If they have columns that contain all the same truth values for each row, then they are equivalent.

## Logical AND

Logical AND is a compound logical operator that is true if and only if both of its components are true.

## Logical OR

Logical OR is a compound logical operator that is true if at least one of its components is true.

## Exclusive OR

Logical Exclusive OR is a compound logical operator that is true if and only if exactly one of its components is true.

## Negation

Logical Negation is a logical operator that only applies to a single proposition. It flips the truth value of the proposition, meaning it is true if the proposition is false, and vice versa.
